# STCR TTN Production Flow V6

ไฟล์พร้อมใช้งาน:

`output/node-red/ttn-production-complete-v6.json`

## โครงสร้าง 3 แท็บ

### 01 ข้อมูลเตาและ MQTT

- กำหนดรอบอ่านและกู้ข้อมูล
- อ่านสถานะทำงาน สถานะอุ่น และเลขรอบ
- อ่านอุณหภูมิ ความชื้น และ Blower
- ส่งค่าที่ตรวจครบ
- Retry
- ส่ง Topic `test` และ `sensor`

### 02 ไฟฟ้าและรายงาน

- อ่านแรงดัน AB/BC/CA
- ตรวจไฟเกิน/ไฟตกและสร้าง Alarm
- Retry จุดอ่านไฟฟ้า
- ปุ่มทดสอบส่งแรงดัน
- รายงานรายชั่วโมง

### 03 ส่ง LINE

- รับข้อความ
- สร้าง Payload
- รายงานรายชั่วโมงแสดงแรงดัน AB/BC/CA และเฉพาะเตาที่เปิด
- ตารางใช้รูปแบบ `เตา,ครั้ง,Tห้อง,Tเตา,Tโบเวอร์,%ชื้น`
- จัดคิว
- ส่ง LINE Messaging API
- ตรวจผลการส่ง

## วิธีเปลี่ยน

1. Export `All flows` สำรอง
2. ลบแท็บ V5 แต่ยังไม่ Deploy
3. Import V6 แบบ `New Flow`
4. ปิด DB, notify และ V2-V5 เดิม
5. เปิดแท็บ V6 ทั้ง 3 แท็บ
6. กด `Deploy > Full`
7. รอ 2 นาที แล้วตรวจเตา 1-9, MQTT, ค่าไฟ, รายงาน และ LINE

ไฟล์มี LINE Token จริง ห้ามอัป Git หรือเผยแพร่
