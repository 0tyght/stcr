# TTN Node-RED V10: แก้ค่าอุณหภูมิเตา 0°C หลุดมาเป็น Alarm

ไฟล์นำเข้า: `output/node-red/ttn-production-complete-v10.json`

## ต้นเหตุ

Flow เดิมยอมรับอุณหภูมิเตาในช่วง `-40 ถึง 1000°C` จึงทำให้ค่า `0` ที่ PLC ส่งมาชั่วคราวผ่านการตรวจ และถูกตีความว่าอุณหภูมิต่ำจริง หลังจากอ่านครั้งต่อไปได้ค่าปกติ ระบบจึงแจ้ง “กลับสู่ช่วงปกติ” สลับไปมา

## สิ่งที่แก้

- เมื่อเตาเปิด ค่าอุณหภูมิเตา `0°C` จะถูกทิ้งทั้งชุด
- ค่าที่ถูกทิ้งจะไม่เข้า MQTT เว็บไซต์ กราฟ ฐานข้อมูล หรือ LINE
- คงค่าล่าสุดที่ตรวจสอบแล้วไว้จนกว่าจะอ่านค่าที่ถูกต้องได้
- ถ้าพบค่าศูนย์ ค่าว่าง ค่าไม่ครบ หรือ Timeout จะอ่านจุดที่ผิดใหม่ทันที สูงสุด 5 ครั้ง ห่างกันครั้งละ 1.5 วินาที
- หากยังอ่านไม่ได้ จะไม่ส่งข้อมูลชุดนั้นและไม่ส่งรายละเอียดข้อผิดพลาดไป LINE จากนั้น Watchdog จะลองใหม่ทุกนาทีจนกว่าจะได้ข้อมูล
- เมื่ออ่านสำเร็จจึงส่งข้อมูลตามปกติ โดยไม่แทนค่าที่หายด้วยเลขศูนย์
- Alarm อุณหภูมิเตาต่ำ สูง และกลับปกติ ต้องพบช่วงใหม่ 2 รอบติดต่อกัน
- แก้ครบเตา TTN 1–9

## วิธีใช้งาน

1. Export สำรอง Flow ที่กำลังใช้งาน
2. ปิดแท็บ Flow TTN ชุดเดิมแล้ว Deploy
3. Import `ttn-production-complete-v10.json`
4. เปิดแท็บของชุดใหม่ทั้งหมดและทำ Full deploy
5. ตรวจว่าไม่มี Flow TTN รุ่นเดิมเปิดพร้อมกัน

ไฟล์ V10 ถูกตั้งให้ Disabled ตอน Import เพื่อป้องกันการทำงานชนกับ Flow เดิมก่อนผู้ดูแลตรวจสอบ
