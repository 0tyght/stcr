# STCR TTN V7 — Local Data และส่งย้อนหลัง

## หลักการ

1. รับค่าครบจาก PLC และสร้าง Payload เหมือน V6
2. บันทึก Payload ลง `C:\STCR\data\stcr-buffer.db` ก่อนส่งทุกครั้ง
3. ส่งรายการ `pending` ตามลำดับเก่าไปใหม่ผ่าน MQTT QoS 1
4. เซิร์ฟเวอร์ส่ง ACK ที่ `stcr/ack/ttn` หลังประมวลผลฐานข้อมูลสำเร็จ
5. เมื่อได้รับ ACK จึงเปลี่ยนรายการเป็น `sent`
6. รายการ `sent` ถูกลบเมื่อครบ 7 วัน ส่วนรายการที่ยังไม่สำเร็จจะไม่ถูกลบ

## การกลับมาทำงาน

- Node-RED รีสตาร์ต: รายการ `inflight` ทั้งหมดจะกลับเป็น `pending`
- อินเทอร์เน็ตหลุด: ข้อมูลใหม่ยังถูกเก็บใน SQLite
- อินเทอร์เน็ตกลับมา: ส่งรายการเก่าสุดก่อนด้วยอัตราสูงสุดประมาณ 2 ข้อความต่อวินาที
- MQTT หรือเซิร์ฟเวอร์ไม่ตอบ ACK ภายใน 30 วินาที: นำรายการกลับมาลองใหม่

## ติดตั้งที่เครื่องโรงงาน

เปิด PowerShell ด้วยผู้ใช้เดียวกับที่รัน Node-RED:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-stcr-node-red-local-buffer.ps1
```

จากนั้นรีสตาร์ต Node-RED หนึ่งครั้ง, Import `ttn-production-complete-v7.json`,
ปิด V6, เปิด V7 และ Deploy

Node-RED ที่ตั้งให้เปิดพร้อม Windows อยู่แล้วจะเปิด V7 และส่งคิวค้างต่อเอง
โดยไม่ต้องรันฐานข้อมูลหรือเซิร์ฟเวอร์อีกตัว
