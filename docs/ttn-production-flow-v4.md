# STCR TTN Production Flow V4

ไฟล์พร้อม Import:

`output/node-red/ttn-production-complete-v4.json`

## สิ่งที่เปลี่ยนจาก V3

- แยกกรอบเตา 1-9 ชัดเจน พร้อมระบุ PLC 183/184/185
- ย้าย Retry เข้าไปในกรอบของแต่ละเตา จึงไม่มีเส้นจาก Switch กลางไขว้ทุกเตา
- ใช้ Link สำหรับส่ง MQTT และ LINE เพื่อลดเส้นยาวข้ามหน้า
- เพิ่ม Watchdog กู้ข้อมูลเฉพาะเตาที่ไม่มีข้อมูลครบในรอบล่าสุด
- ย้ายรอบอ่านแรงดันเป็นวินาที 17 ไม่ชนกับรอบหลักและรอบกู้ข้อมูลเตา 1
- แยกกรอบแรงดันไฟฟ้าและรายงานรายชั่วโมงออกจากกลุ่มเตา

## วิธีเปลี่ยนเป็น V4

1. Export `All flows` สำรองก่อน
2. Import `ttn-production-complete-v4.json` แบบ `New Flow`
3. ตรวจว่า Environment ของแท็บ LINE V4 มีค่าครบ
4. ปิดแท็บ DB, notify, V2 และ V3 เดิมทั้งหมด
5. เปิดแท็บ `STCR · TTN Production V4` และ `STCR · ส่ง LINE (V4)`
6. กด `Deploy > Full` หนึ่งครั้ง
7. รอ 2 นาที ตรวจ Debug และเวลาล่าสุดของเตา 1-9
8. ทดสอบ LINE และปุ่มทดสอบแรงดัน AB/BC/CA

ไฟล์ V4 มี LINE Token จริง ห้ามอัป Git หรือส่งต่อสาธารณะ
