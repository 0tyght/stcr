# STCR TTN Production Flow V5

ไฟล์พร้อมใช้งาน:

`output/node-red/ttn-production-complete-v5.json`

## การแยกงาน

1. `01 รับและตรวจข้อมูลเตา`
   - กำหนดรอบอ่านและกู้ข้อมูล
   - อ่านสถานะทำงาน สถานะอุ่น และเลขรอบ
   - อ่านอุณหภูมิ ความชื้น และ Blower
   - ส่งค่าที่ตรวจครบ
   - Retry แยกจากเส้นหลักด้วย Link
2. `02 ส่งข้อมูล MQTT`
   - รวมสถานะไป Topic `test`
   - รวมเซนเซอร์ไป Topic `sensor`
3. `03 ตรวจแรงดันไฟฟ้า`
   - อ่าน AB/BC/CA
   - ตรวจไฟเกิน/ไฟตก
   - Retry และทดสอบส่งค่า
4. `04 รายงานรายชั่วโมง`
   - ตรวจข้อมูลครบ 9 เตาและแรงดัน
   - รอข้อมูลที่ขาดก่อนส่ง
5. `05 ส่ง LINE`
   - สร้าง Payload
   - จัดคิวหนึ่งข้อความต่อวินาที
   - ส่งและตรวจผล

## วิธีเปลี่ยน

1. Export `All flows` สำรอง
2. ลบแท็บ V4 ปัจจุบัน แต่ยังไม่ Deploy
3. Import V5 แบบ `New Flow`
4. ปิด DB, notify, V2, V3 และ V4 เดิม
5. เปิดแท็บ V5 ทั้ง 5 แท็บ
6. `Deploy > Full`
7. รอ 2 นาทีแล้วตรวจเตา 1-9, MQTT, ค่าไฟ และ LINE

ไฟล์มี LINE Token จริง ห้ามอัป Git หรือเผยแพร่
